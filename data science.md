# Data Science — Project Catalog (DS-701 – DS-750)

50 IEEE-paper-inspired Data Science projects, numbered `DS-701` through `DS-750` per this repo's domain prefix registry (see `HOWTO-Create-Domain-Project-List.md`).

**Every project in this domain requires ZERO model training of its own.** Each is either (a) a deterministic statistical/algorithmic computation — EDA, profiling, imputation, outlier scoring, correlation, hypothesis testing, ARIMA/exponential-smoothing curve-fitting run fresh on the given series, k-means/DBSCAN/hierarchical clustering, PCA/t-SNE projection, LDA topic inference, Apriori/FP-Growth/Eclat pattern mining, RFM quantile scoring, cosine/Pearson similarity, k-anonymity/differential-privacy transforms, distribution-based synthetic sampling — computed directly on a given dataset instance with no reusable model persisted for future generalization, or (b) a tool that calls an EXISTING pretrained model (HuggingFace transformer sentiment/embedding pipelines) purely via inference, with zero fine-tuning. Nothing in this list requires a GPU, a labeled training dataset used to fit a predictive model for reuse, or a training loop. Where a project's cited paper itself explores a trained/learned technique (e.g. ANN sales forecasting, K-means-based RFM clustering, boundary-shrinking drift detectors), the project scope below deliberately reuses only that paper's real problem framing and its deterministic/statistical components — never the model-fitting step.

**Also recently published:** unlike some earlier domains in this catalog, this list deliberately favors 2018–2025 papers, with several from 2024-2025 — flagged per-row where a paper is a foundational older reference (rare in this domain; only 3 rows predate 2010).

## Zero-Cost, Zero-Training Stack
- **Core statistical/algorithmic libraries (no training):** pandas, NumPy, SciPy (hypothesis tests, distributions), statsmodels (ARIMA/exponential smoothing — curve-fit-in-place, not a persisted reusable model), scikit-learn (used only for direct computation: PCA, t-SNE, k-means/DBSCAN clustering run fresh each time, never as a saved/reused classifier), mlxtend (Apriori/FP-Growth), gensim (LDA topic inference), NetworkX (lineage graphs).
- **Pretrained-inference-only:** HuggingFace `transformers` sentiment pipelines (e.g. `cardiffnlp/twitter-roberta-base-sentiment`, `distilbert-base-uncased-finetuned-sst-2-english`) — loaded and called for inference, never fine-tuned.
- **Privacy/synthetic-data:** `diffprivlib` (differential privacy noise injection), custom k-anonymity generalization, `copulas` (Gaussian Copula statistical fitting for synthetic sampling — a closed-form distribution fit, not an iteratively trained model).
- **UI:** Streamlit for every project — upload data, run the deterministic/statistical pipeline, view results interactively.
- **Data:** self-authored sample CSVs or small public datasets (UCI, Kaggle-public, synthetic self-generated) — no training-dataset curation required since nothing is fit for generalization.
